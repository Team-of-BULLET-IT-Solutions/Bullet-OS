Bullet-OS v1.0

A sleek, high-performance Linux-based Mobile Operating System (AOSP Core + Bullet Hardware Abstraction) engineered for pure speed and modern security.

  • ▶ Native Android Compatibility: Full APK execution via ART runtime.
  • ▶ Bullet Performance Engine: C++ `bulletd` daemon for dynamic CPU governor management.
  • ▶ Generic System Image (GSI): Flashable on any Project Treble Android device.
  • ▶ PC Emulator / QEMU: Test on x86_64 machines with zero hardware lock-in.
  • ▶ Bullet Shield: Strict hardware isolation and privacy controls.
